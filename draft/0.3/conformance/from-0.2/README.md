# Cases from the 0.2 suite

These files are the 0.2 conformance suite's repository cases (`repositories.json`), structural schema cases (`schema-cases.json`) and requirement map (`suite.json`), kept unchanged as input for step 2b of the [plan](../../plan-agent-readiness.md). They use wire 0.2 and its requirement IDs OSTF-001 to OSTF-024; [Annex H](../../ostf.md#annex-h-informative-changes-from-draft-02) maps those IDs to 0.3. Nothing runs them. Each case moves to [cases.json](../cases.json) once it is rewritten for wire 0.3 with its expectation checked against the 0.3 text, and this directory is deleted when none is left.
