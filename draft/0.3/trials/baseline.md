# Phase 1 baseline

The baseline of the [agent-first plan](../plan-agent-first.md), section 6: what OSTF 0.3, as published in document revision 0.13, does for coding agents and for real code before Phase 2 changes anything. Each number below is what a change in Phases 2 and 3 must beat. The [protocol](protocol.md#agent-first-phase-1-three-arms) froze the trials before any scored run; generated by `baseline.py report` from [results/phase1/](results/phase1/).

264 trial runs; agents claude claude-haiku-5-5, codex gpt-6-sol; judge claude-opus-5-5.

## Corroboration

An `implements` link to a function is on tested code when a test verifies the same item, and confirmed when one of those tests, run alone with coverage, executes a statement of the function's body. Links to types and constants are left out, since coverage cannot confirm them ([corroborate.py](corroborate.py)).

| Links | Links to types or constants | On tested code | Confirmed |
| --- | --- | --- | --- |
| Go fixture, as published: 41 | 6 | 33 | 32/33 (97 %, 85 to 99) |
| TypeScript fixture, as published: 42 | 6 | 34 | 33/34 (97 %, 85 to 99) |
| Declared by agents in T2, T4 and T5: 152 | 0 | 152 | 152/152 (100 %, 98 to 100) |

## Recheck

In 72 `full` runs of tasks that change code, the change touched 223 existing links: 208 were stamped again in the same change and 15 left suspect. Agents added 151 links and stamped 151. 25 stamps, in 12 runs, were of risk-relevant links that the stamping agent had changed itself: every one in a T3 run, whose criterion, like the paragraph, has the agent that changed the control stamp it again after the user said yes. 0.3 asks for these self-stamps; Phase 3's separation of duties is to remove them.

## The judge

600 verdicts of claude-opus-5-5. The text matching of rounds 1 to 3 disagreed with the judge on 18 criteria. At the maintainer's request an agent, not a person, labelled the sample of one verdict in ten: Codex gpt-6.1-sol at reasoning effort xhigh, read-only, reading the same material without the judge's verdicts. It agreed with the judge on 59/60 (98 %, 91 to 100) of 60; it differed on `claude.none.go-shop.T7.3` `item:R-DISCOUNT-EXPIRY`. A person's labels, which the plan asks for, are still open in [results/phase1/human-sample.md](results/phase1/human-sample.md).

## Cost

As the CLIs report it, in API-equivalent dollars: Claude Code agents in the trials and the parallel fixture 1.78 USD; the judge 8.11 USD, re-judging included; backfilling the replay repositories 8.01 USD; labelling their suspect links 18.53 USD. Codex reports tokens, not prices: 38,092,488 input tokens, of them 34,264,960 cached, and 460,975 output and reasoning tokens. Not counted: the session that ran the phase, the pilot, the first py-repo backfill, which linked dead code and cost 1.34 USD, and the labelling of the sample of verdicts by Codex.

After the scored runs, 72 T1 and T7 records were judged again and the T5 and lock corrections applied, as the [protocol](protocol.md#corrections) records; 19 records changed from fail to pass or back.
