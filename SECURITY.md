# Security policy

The `main` branch is a working draft. The Python reader and conformance tools are development aids, not hardened services for untrusted input. There is no stable OSTF release or security backport program yet.

Report a vulnerability in the reader, schemas, fixtures, build workflow or repository privately through [GitHub's vulnerability reporting](https://github.com/ostf-spec/ostf/security/advisories/new) or at [security@ostf.dev](mailto:security@ostf.dev). Please include a minimal reproducer, the affected revision and the impact. Do not put exploit details in a public issue before maintainers have had a chance to investigate.

For a specification ambiguity or an ordinary validation disagreement, use an [issue](https://github.com/ostf-spec/ostf/issues/new/choose). No response or fix deadline is promised for this working draft. Maintainers will coordinate disclosure with the reporter when a report concerns a real vulnerability.
